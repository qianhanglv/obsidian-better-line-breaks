# 更好的换行体验（Better Line Breaks）

**English → [README.md](README.md)**

一个让 Obsidian 拥有 **Typora 式换行体验** 的插件。

从 Typora 搬到 Obsidian 的人大多会撞上三件事：按一次回车不是真正的分段、Shift+Enter 不像是"段内换行"、在段首按退格没法干净地落到上一段末尾。这个插件补上这三件事，外加把粘贴进来的纯文本整理成段落。

## 开始之前

**请关闭「严格换行」**（设置 → 编辑器 → 严格换行）。

Obsidian 默认是开启的。开着的时候，`Shift+Enter` 写进去的单个 `\n` 在阅读视图里会被渲染成空格，软换行就失效了。插件检测到它开启时会弹出一次提示。

## 它做什么

| 动作 | 行为 |
|---|---|
| **Enter** | 恒定插入两个换行符（真正的段落分隔） |
| **Shift+Enter** | 恒定插入一个换行符（段内软换行） |
| **段首退格** | 看光标前连续换行的个数：**偶数** → 删掉两个；**奇数** → 只删一个。光标永远停在正文行上 |
| **粘贴** | 纯文本硬折行（只有单换行、没有空行、没有 Markdown 语法）会被拆成段落；看起来像 Markdown 的内容原样插入 |
| **空行** | 渲染成较窄的段间距，不再占一整行 |

每个行为都有独立开关。列表、引用、表格、代码块、公式块、YAML 属性区**完全不动**，保持 Obsidian 原生行为。

## 安装

### 从插件市场

设置 → 第三方插件 → 浏览 → 搜索 **Better Line Breaks**（或搜 **typora**）。

### 手动

下载[最新 release](https://github.com/qianhanglv/obsidian-better-line-breaks/releases/latest) 里的 `main.js`、`manifest.json`、`styles.css`，放进：

```
<你的库>/.obsidian/plugins/typora-flow/
```

然后在 设置 → 第三方插件 里启用。

## 设置

| 设置项 | 默认 | 作用 |
|---|---|---|
| Enter / Shift+Enter 换行 | 开 | 回车分段、Shift+Enter 软换行 |
| 段首退格 | 开 | 按奇偶跨过空行 |
| 粘贴时整理段落 | 开 | 把硬折行的纯文本拆成段落 |

单次粘贴想绕开整理：命令面板执行「原样粘贴 / Paste as-is」。

## 几个细节

- **中文输入法安全**：组词状态下按回车不会被拦截，选词照常。
- **退格的奇偶**：光标前是 2 个换行 → 删 2 个（两段合并）；是 3 个 → 只删 1 个，留下标准的 2 个换行。这样一次按键永远不会塌掉超过一个段落分隔。
- **软换行是真换行**：Shift+Enter 写进文件的就是一个 `\n`。它在编辑器里仍然是一行真实的行，插件做不到让它"消失"，只能把**空行**在视觉上压窄。
- **段间距**：改 `styles.css` 里的 `--tf-paragraph-gap`（默认 `0.9em`）。

## 已知边界

- 列表、引用、表格、代码块、公式块内一律不接管。
- 粘贴时不会"还原硬折行"：已经带空行的文本被视为有意的段落结构，原样插入。
- 目前仅桌面端。

## 开发

不需要构建，`main.js` 是纯 CommonJS，本身就是源码。

